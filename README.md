# MyShop Final Project

## 🚀 Запуск проекта

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Скопировать `.env_template` в `.env` и отредактировать параметры подключения к базе данных.

3. Применить миграции:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

4. Создать суперпользователя:
   ```bash
   python manage.py createsuperuser
   ```

5. Загрузить тестовые данные (фикстуры):
   ```bash
   python manage.py load_test_data
   ```

6. Запустить сервер:
   ```bash
   python manage.py runserver
   ```

---

### ✅ Валидация:
- **Запрещённые слова** в полях `name` и `description`:  
  `казино, криптовалюта, крипта, биржа, дешево, бесплатно, обман, полиция, радар`.  
  Если пользователь введёт одно из этих слов, форма вернёт ошибку.

- **Цена (`price`)**:  
  Не может быть отрицательной. При неверном значении появляется ошибка валидации.

- **Изображение (`image`)** (доп. задание):  
  Допускаются только JPEG/PNG, размером не более **5 МБ**.

---

### 🖌️ Стилизация:
- Все поля формы используют классы Bootstrap.  
- Булевое поле отображается как чекбокс.
